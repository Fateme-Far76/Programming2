# Programming2

Welcome to the Programming2 Assignment Repository! This repository contains my submission for the Programming2 course assignment at Hanze university of Applied Sciences.

## Repository Structure
- `Assignment 1.1/`: Static code analysis 
- `Assignment 1.2/`: Classes and instances
- `Assignment 1.3/`:  Multiple class interaction
- `Assignment 1.4/`: Generators, and map-reduce
- `Assignment 2.1/`: Network operations
- `Assignment 2.2/`: Parallellisasion
- `Assignment 2.5/`: Real world Dask
- `Assignment 2.6/`: Software Engineering for Machine Learning(1)
- `Assignment 2.7/`: Software Engineering for Machine Learning(2)
